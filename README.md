# Gergram — форк Telegram для macOS с функциональностью AyuGram

Цель проекта: перенести функциональность **AyuGram Desktop** (форк Telegram Desktop)
в нативный **Swift-клиент Telegram для macOS** и составить полный перечень фич.

## Ограничения (обязательно к соблюдению)

- **GitHub — только `geranton93`.** Корпоративный аккаунт `antonh-ai-districtcyber` не
  используется. В `.git/config` репозитория уже закреплён персональный SSH-ключ и
  `user.name`/`user.email`; для `gh` обязательно `GH_TOKEN="$(gh auth token --user geranton93)"`.
- **GPL-2.0.** Форк публикуется под GPL-2.0, со своими API-ключами, своим именем и иконкой.
- Подробности и команды — в [`docs/00-constraints.md`](docs/00-constraints.md).

## Короткий вывод

1. **Реализовать можно практически всё.** 120 из 124 фич AyuGram реализуются
   исключительно в Swift-UI-слое. Из них 21 уже есть в апстримном клиенте —
   нужен только переключатель.
2. **Ядро нужно трогать в 4 местах.** Полный Ghost Mode (подавление online-пакетов,
   прогресса загрузки, typing) плюс скруглённые стикеры и масштабирование ленты
   требуют собственного форка подмодуля `telegram-ios`. Это основная сложность
   и постоянная работа на merge.
3. **Архитектура благоприятна.** Настройки в Swift-клиенте — `Codable`-структуры
   в `UserDefaults`, поэтому сотня флагов AyuGram добавляется одной структурой,
   а не 200 патчами по коду, как в самом AyuGram.
4. **Оценка:** 85–143 человеко-дня для Swift-части, 105–178 с форком ядра.
